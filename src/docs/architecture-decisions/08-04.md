# Architecture Decision — Transaction Listesini Persistence Adapterında Domain Listesine Dönüştürmek

- **Tarih:** 08-04
- **Durum:** Kabul edildi

## Bağlam

Spring Data repository’si işlem sorgularında:

```java
List<TransactionJpaEntity>
```

döndürmektedir.

Application katmanındaki `TransactionRepository` portu ise:

```java
List<Transaction>
```

dönüşünü beklemektedir.

BankService’in JPA entity türlerini bilmemesi gerekir.

## Karar

Entity listesinin domain listesine dönüşümü `PostgreSqlTransactionRepositoryAdapter` içinde yapılacaktır.

Dönüşüm:

```java
.stream()
.map(this::toDomain)
.toList();
```

ile gerçekleştirilecektir.

Tekil kayıt dönüşümleri de aynı adapter içindeki:

```text
toEntity
toDomain
```

methodlarında tutulacaktır.

## Gerekçe

- BankService ve application portlarının JPA türlerinden bağımsız kalması
- Domain–persistence dönüşüm sorumluluğunun adapterda toplanması
- Customer ve Account adapterlarıyla aynı mimari şablonun korunması
- Liste dönüşümünün kısa ve okunabilir biçimde ifade edilmesi
- Nullable hedef hesap değerinin domain modeline kontrollü aktarılması

## Sonuçlar

### Olumlu

- Application katmanı yalnızca domain `Transaction` nesnelerini görür.
- Spring Data ayrıntıları persistence katmanında kalır.
- Tekil ve liste dönüşümleri aynı yerde yönetilir.
- Üç repository adapterı ortak bir mimari desen izler.

### Maliyet

- Her entity için dönüşüm kodu yazılması gerekir.
- Çok büyük listelerde bütün kayıtlar bellekte domain nesnelerine çevrilir.
- Dönüşüm kuralları değiştiğinde adapterın güncellenmesi gerekir.
