# 07-27 — Spring Boot ile PostgreSQL Bağlantısı

## Günün Amacı

Bu çalışmada Spring Boot uygulamasının yerel PostgreSQL veritabanına bağlanması sağlandı.

Henüz mevcut `InMemory` repository’ler değiştirilmedi. Amaç yalnızca şu bağlantıyı hazırlamak ve doğrulamaktı:

```text
Spring Boot
    ↓
JDBC
    ↓
PostgreSQL Driver
    ↓
bank_user
    ↓
bank_db
```

## Maven Dependency’leri

`pom.xml` dosyasına şu iki dependency eklendi:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

Mevcut JUnit dependency’si değiştirilmedi.

Dependency’ler ilk eklemede IntelliJ’de kırmızı göründü. Sorun:

```text
pom.xml → Maven → Sync
```

ile çözüldü.

## Dependency’lerin Görevleri

### `spring-boot-starter-data-jpa`

```text
JPA
Hibernate
Spring Data JPA
Spring ORM
```

bileşenlerini getirir.

### PostgreSQL JDBC Driver

Java uygulamasının PostgreSQL ile iletişim kurmasını sağlar.

## JDBC Nedir?

JDBC, Java uygulamalarının ilişkisel veritabanlarıyla konuşmak için kullandığı standart bağlantı sistemidir.

```text
Java / Spring Boot
        ↓ JDBC
PostgreSQL Driver
        ↓
PostgreSQL Server
```

## `application.properties`

Dosya:

```text
src/main/resources/application.properties
```

Eklenen ayarlar:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/bank_db
spring.datasource.username=bank_user
spring.datasource.password=${BANK_DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=none
```

### Datasource URL

```text
jdbc:postgresql → PostgreSQL JDBC bağlantısı
localhost       → Veritabanı bu bilgisayarda
5432            → PostgreSQL portu
bank_db         → Bağlanılacak veritabanı
```

### Kullanıcı

```properties
spring.datasource.username=bank_user
```

Spring Boot, PostgreSQL’e uygulama için oluşturulan teknik kullanıcıyla bağlanır.

### Şifre

```properties
spring.datasource.password=${BANK_DB_PASSWORD}
```

Gerçek şifre dosyaya yazılmadı. Değer environment variable’dan alınır.

```text
Şifre GitHub’a gönderilmez
Şifre application.properties içinde görünmez
Yerel ayar kaynak koddan ayrılır
```

## Environment Variable

Şifre IntelliJ terminalinde tanımlandı:

```bash
export BANK_DB_PASSWORD='gercek_sifre'
```

Ardından aynı terminalde uygulama başlatıldı:

```bash
mvn spring-boot:run
```

İki komutun aynı terminal oturumunda çalıştırılması gerekir.

```text
psql terminali     → SQL komutları
IntelliJ terminali → Maven, Java ve işletim sistemi komutları
```

## `ddl-auto=none`

```properties
spring.jpa.hibernate.ddl-auto=none
```

Bu aşamada Hibernate’e veritabanı şemasını değiştirmemesi söylendi:

```text
Tablo oluşturma
Tablo silme
Sütun değiştirme
```

İlk hedef yalnızca bağlantıyı doğrulamaktı.

## Başarılı Bağlantı Logları

Uygulama çalıştırıldığında şu satırlar görüldü:

```text
HikariPool-1 - Added connection ...
HikariPool-1 - Start completed.
```

Veritabanı bilgileri:

```text
Database JDBC URL: jdbc:postgresql://localhost:5432/bank_db
Database driver: PostgreSQL JDBC Driver
Database version: 18.4
Default catalog/schema: bank_db/public
```

Web sunucusu:

```text
Tomcat started on port 8080 (http)
```

Uygulama başlangıcı:

```text
Started BankApplication
```

Bu loglar Spring Boot’un başladığını, Tomcat’in 8080 portunda çalıştığını ve PostgreSQL bağlantısının başarıyla kurulduğunu doğrular.

## Neden `BUILD SUCCESS` Görünmedi?

```bash
mvn spring-boot:run
```

uygulamayı çalışır durumda bırakır. Program sonlanmadığı için Maven henüz `BUILD SUCCESS` satırına geçmez.

Uygulamayı durdurmak için:

```text
Control + C
```

kullanılır.

## Mevcut Repository Durumu

PostgreSQL bağlantısı kurulmuş olsa da uygulama verileri henüz PostgreSQL’e yazılmamaktadır.

```text
Controller
   ↓
BankService
   ↓
Repository portu
   ↓
InMemory repository
   ↓
Map / List
```

Bağlantının kurulması, repository implementasyonlarının otomatik olarak PostgreSQL’e geçtiği anlamına gelmez.

## Hedef Persistence Yapısı

```text
Controller
   ↓
BankService
   ↓
Aynı repository portu
   ↓
PostgreSQL persistence adapter
   ↓
bank_db
```

Hexagonal mimari sayesinde `BankService`, verinin RAM’de mi PostgreSQL’de mi tutulduğunu doğrudan bilmeyecektir.
