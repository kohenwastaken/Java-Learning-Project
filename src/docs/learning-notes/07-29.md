# 07-29 — Spring Data JPA Repository Yapısı

## Günün Amacı

Bu çalışmada `JpaRepository` yapısı öğrenildi ve `CustomerJpaEntity` için `CustomerSpringDataRepository` oluşturuldu.

## Repository Interface'i

```java
public interface CustomerSpringDataRepository
        extends JpaRepository<CustomerJpaEntity, Integer> {
}
```

Dosya:

```text
adapter/out/persistence/repository/CustomerSpringDataRepository.java
```

## `JpaRepository` Nereden Gelir?

```java
import org.springframework.data.jpa.repository.JpaRepository;
```

Bu interface şu dependency sayesinde projeye gelir:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

## Generic Türler

```java
JpaRepository<CustomerJpaEntity, Integer>
```

şu anlama gelir:

```text
CustomerJpaEntity
→ Repository'nin yönettiği entity

Integer
→ Entity'nin primary key türü
```

## Hazır Methodlar

`JpaRepository` üzerinden temel işlemler hazır gelir:

```java
save(entity)
findById(id)
findAll()
existsById(id)
deleteById(id)
count()
```

### `save(entity)`

Yeni kaydı eklemek veya mevcut kaydı güncellemek için kullanılır.

```text
Yeni kayıt    → yaklaşık INSERT
Mevcut kayıt → yaklaşık UPDATE
```

### `findById(id)`

Primary key üzerinden arama yapar:

```java
Optional<CustomerJpaEntity>
```

Kayıt bulunmazsa `Optional.empty()` döner.

### `findAll()`

Tablodaki tüm kayıtları getirir.

### `existsById(id)`

Belirtilen ID'ye sahip kayıt olup olmadığını `boolean` olarak döndürür.

### `deleteById(id)`

Belirtilen ID'ye sahip kaydı siler.

### `count()`

Toplam kayıt sayısını döndürür.

## Boş Interface Nasıl Çalışır?

Spring, uygulama açılırken repository interface'lerini tarar ve çalışma anında bunlar için bir implementation/proxy nesnesi üretir.

```text
CustomerSpringDataRepository
        ↓
Spring'in ürettiği proxy
        ↓
JpaRepository methodları
        ↓
Hibernate / EntityManager
        ↓
PostgreSQL
```

Bu nedenle ayrıca `CustomerSpringDataRepositoryImpl` yazılması gerekmez.

## Özel Sorgu Methodları

İleride şu şekilde method isimlerinden sorgu üretilebilir:

```java
List<CustomerJpaEntity> findBySurname(String surname);
```

Bu çalışmada yalnızca hazır `save` ve `findById` işlemleri yeterli olduğu için özel method eklenmedi.

## İki Repository'nin Farkı

```text
CustomerRepository
→ Uygulamanın output portudur.
→ Customer domain modeliyle çalışır.
→ BankService bunu tanır.

CustomerSpringDataRepository
→ Spring Data JPA repository'sidir.
→ CustomerJpaEntity ile çalışır.
→ PostgreSQL erişiminde kullanılır.
```

BankService doğrudan Spring Data repository'sine bağlanmadı.
