# 08-07 — PostgreSQL Temelleri ve Spring Boot Bağlantısı

## Günün Amacı

Bankacılık uygulamasında verilerin uygulama kapandığında kaybolmaması için PostgreSQL kullanılmaya başlandı. PostgreSQL’in temel kavramları öğrenildi, uygulama için ayrı bir veritabanı ve teknik kullanıcı oluşturuldu ve Spring Boot bağlantısı doğrulandı.

## PostgreSQL Nedir?

PostgreSQL ilişkisel bir veritabanı yönetim sistemidir. Veriler tablolar, satırlar ve sütunlar halinde tutulur.

Örnek yapı:

```text
customers
accounts
transactions
```

Primary key, tablodaki her kaydı benzersiz olarak tanımlar. Aynı primary key değeri iki farklı kayıt için kullanılamaz.

## SQL

SQL ilişkisel veritabanlarıyla iletişim kurmak için kullanılan sorgu dilidir. Temel CRUD işlemleri Create, Read, Update ve Delete olarak düşünülebilir.

Örnek:

```sql
SELECT * FROM customers;
```

## PostgreSQL Kullanıcısı ve Veritabanı

Uygulamanın PostgreSQL’e bağlanması için teknik kullanıcı oluşturuldu:

```sql
CREATE ROLE bank_user WITH LOGIN;
```

Parola:

```sql
\password bank_user
```

Uygulama veritabanı:

```sql
CREATE DATABASE bank_db OWNER bank_user;
```

Bağlantı:

```bash
psql -h localhost -p 5432 -U bank_user -d bank_db
```

ile test edildi.

`bank_user`, uygulamadaki banka müşterisi değildir. PostgreSQL bağlantısı için kullanılan teknik kullanıcıdır. `Customer` ise uygulamanın domain modelidir.

## Spring Boot Datasource Ayarları

`application.properties` içinde PostgreSQL bağlantısı tanımlandı:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/bank_db
spring.datasource.username=bank_user
spring.datasource.password=${BANK_DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=none
```

Veritabanı parolası kaynak koduna yazılmadı. Environment variable kullanıldı:

```bash
export BANK_DB_PASSWORD='...'
```

## Maven Bağımlılıkları

Persistence için Spring Data JPA ve PostgreSQL JDBC driver kullanıldı:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

## Bağlantının Doğrulanması

Spring Boot başlatıldığında HikariCP üzerinden PostgreSQL bağlantısının kurulduğu loglardan doğrulandı.

```text
Spring Boot
↓
JDBC / Spring Data JPA
↓
PostgreSQL
```

## Gün Sonu Çıkarımı

PostgreSQL ortamı hazırlandı ve Spring Boot uygulamasının veritabanına bağlanabildiği doğrulandı. Bu aşamada amaç bağlantıyı kurmak ve temel veritabanı kavramlarını öğrenmekti.
