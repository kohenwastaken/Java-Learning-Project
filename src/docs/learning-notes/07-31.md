# 07-31 — Account Persistence Modeli ve Repository Adapterı

## Günün Amacı

Bu çalışmada Customer tarafında kurulan persistence yapısının benzeri Account modeli için oluşturuldu.

Eklenen parçalar:

```text
AccountJpaEntity
AccountSpringDataRepository
PostgreSqlAccountRepositoryAdapter
```

## Domain Modeli

`Account` sınıfı şu alanlara sahiptir:

```java
private final int accID;
private BigDecimal balance;
```

Ayrıca para yatırma, çekme, gönderme ve alma kurallarını içerir.

Bu iş kuralları domain sınıfında bırakıldı.

## `AccountJpaEntity`

```java
@Entity
@Table(name = "accounts")
public class AccountJpaEntity {

    @Id
    @Column(name = "account_id")
    private Integer accountId;

    @Column(
            nullable = false,
            precision = 19,
            scale = 2
    )
    private BigDecimal balance;

    protected AccountJpaEntity() {
    }

    public AccountJpaEntity(
            Integer accountId,
            BigDecimal balance
    ) {
        this.accountId = accountId;
        this.balance = balance;
    }
}
```

## İş Kuralları Neden Entity'de Değil?

```text
Account
→ İş kurallarını bilir.

AccountJpaEntity
→ Yalnızca account_id ve balance sütunlarını temsil eder.
```

Entity'ye şu methodlar taşınmadı:

```java
moneyDeposit(...)
moneyWithdraw(...)
moneySend(...)
moneyReceive(...)
```

## `BigDecimal`

Bakiye için `BigDecimal` kullanılmaya devam edildi. `double` ve `float` bazı ondalık değerleri tam temsil edemediğinden finansal hesaplamalar için uygun değildir.

## `precision` ve `scale`

```java
precision = 19,
scale = 2
```

PostgreSQL tarafında yaklaşık olarak:

```text
NUMERIC(19, 2)
```

karşılığına gelir.

```text
precision → Toplam basamak sayısı
scale     → Ondalık basamak sayısı
```

## `AccountSpringDataRepository`

```java
public interface AccountSpringDataRepository
        extends JpaRepository<AccountJpaEntity, Integer> {
}
```

```text
AccountJpaEntity → Yönetilen entity
Integer          → Primary key türü
```

Hazır `save`, `findById`, `findAll` ve benzeri methodları sağlar.

## `PostgreSqlAccountRepositoryAdapter`

```java
public class PostgreSqlAccountRepositoryAdapter
        implements AccountRepository {

    private final AccountSpringDataRepository springDataRepository;

    public PostgreSqlAccountRepositoryAdapter(
            AccountSpringDataRepository springDataRepository
    ) {
        this.springDataRepository = springDataRepository;
    }
}
```

Adapter:

```text
AccountRepository portunu uygular.
Account ile AccountJpaEntity arasında dönüşüm yapar.
Spring Data repository'sini kullanır.
```

## Kaydetme Akışı

```java
@Override
public Account save(Account account) {
    AccountJpaEntity entity = toEntity(account);

    AccountJpaEntity savedEntity =
            springDataRepository.save(entity);

    return toDomain(savedEntity);
}
```

```text
Account
   ↓ toEntity
AccountJpaEntity
   ↓ save
PostgreSQL
   ↓
AccountJpaEntity
   ↓ toDomain
Account
```

## Bulma Akışı

```java
@Override
public Optional<Account> findById(int accountId) {
    return springDataRepository
            .findById(accountId)
            .map(this::toDomain);
}
```

```text
Optional<AccountJpaEntity>
        ↓ map
Optional<Account>
```

## Dönüşüm Methodları

```java
private AccountJpaEntity toEntity(Account account) {
    return new AccountJpaEntity(
            account.getAccId(),
            account.getBalance()
    );
}
```

```java
private Account toDomain(AccountJpaEntity entity) {
    return new Account(
            entity.getAccountId(),
            entity.getBalance()
    );
}
```

## Bakiye Güncellemesinin Hazırlığı

BankService önce domain nesnesindeki bakiyeyi değiştirir:

```java
account.moneyDeposit(amount);
```

ve ardından:

```java
accountRepository.save(account);
```

çağırır.

PostgreSQL adapterı etkinleştirildiğinde güncellenen domain nesnesi entity'ye çevrilerek `accounts` tablosuna kaydedilecektir.

## Customer ve Account İçin Ortak Şablon

## Customer–Account İlişkisi

Mevcut domain tasarımında `Customer` ve `Account` aynı ID değerini kullanmaktadır. Bu çalışmada `@OneToOne` veya foreign key ilişkisi eklenmedi.
