# 08-14 — Docker Temelleri ve Spring Boot Uygulamasını Containerize Etmek

## Günün Amacı

Docker kavramlarını öğrenmek ve Spring Boot bankacılık uygulamasını Java 25 ile çalışan bir Docker image hâline getirmek.

## Docker Nedir?

Docker, uygulamaları ihtiyaç duydukları runtime ve bağımlılıklarla birlikte izole container ortamlarında çalıştırmayı sağlar.

Temel kavramlar:

```text
Image
→ container oluşturmak için kullanılan şablon

Container
→ image'ın çalışan instance'ı
```

## Dockerfile

Proje root dizinine `Dockerfile` eklendi.

```dockerfile
FROM maven:3.9.16-eclipse-temurin-25-alpine AS build

WORKDIR /app

COPY pom.xml .

RUN mvn dependency:go-offline

COPY src ./src

RUN mvn clean package -DskipTests

FROM eclipse-temurin:25-jre-ubi10-minimal

WORKDIR /app

COPY --from=build     /app/target/Java-Learning-Project-1.0-SNAPSHOT.jar     app.jar

EXPOSE 8080

ENTRYPOINT ["java", "-jar", "app.jar"]
```

## Multi-Stage Build

İlk stage:

```text
Maven + Java 25 JDK
↓
source code build
↓
JAR
```

İkinci stage:

```text
Java 25 JRE
+
app.jar
```

Final image’a Maven ve source code taşınmadı.

## WORKDIR, COPY, RUN ve ENTRYPOINT

```dockerfile
WORKDIR /app
```

container içindeki çalışma klasörünü belirler.

```dockerfile
COPY ...
```

host’taki dosyaları image build context’inden container filesystem’ine kopyalar.

```dockerfile
RUN ...
```

image build sırasında çalışır.

```dockerfile
ENTRYPOINT ["java", "-jar", "app.jar"]
```

container başladığında çalışır.

## Spring Boot Maven Plugin

Executable JAR üretmek için `pom.xml` içine Spring Boot Maven plugin eklendi:

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
        </plugin>
    </plugins>
</build>
```

## İlk Docker Build

```bash
docker build -t bank-app .
```

komutu ile image oluşturuldu.

İlk denemede dosya adı `DockerFile` olduğu için Docker varsayılan `Dockerfile` adını bulamadı. Dosya yeniden adlandırıldıktan sonra build başarıyla tamamlandı.

## Image ve Java Sürümü Kontrolü

```bash
docker images
```

ile `bank-app:latest` image’ı görüldü.

```bash
docker run --rm --entrypoint java bank-app -version
```

ile container içindeki Java sürümü kontrol edildi.

Sonuç:

```text
OpenJDK 25.0.3
```

olarak doğrulandı.

## Gün Sonu Çıkarımı

Spring Boot uygulaması Java 25 ile çalışan bir Docker image hâline getirildi. Dockerfile, image, container, multi-stage build, build cache, port ve entrypoint kavramları uygulama üzerinde öğrenildi.
