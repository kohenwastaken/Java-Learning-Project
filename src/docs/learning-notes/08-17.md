# 08-17 — Docker Compose, PostgreSQL Container, Volume ve Final Docker Testleri

## Günün Amacı

Spring Boot uygulaması ile PostgreSQL’i iki ayrı container olarak çalıştırmak, Docker Compose ile tek yapı altında yönetmek, database verisini volume ile kalıcı tutmak ve Docker ortamında uçtan uca bankacılık işlemlerini test etmek.

## Docker Desktop Kurulumu

macOS Apple Silicon için Docker Desktop kuruldu.

```bash
docker --version
docker compose version
docker info
```

ile Docker CLI, Docker Compose ve Docker Engine’in çalıştığı doğrulandı.

## Docker Compose

Proje root dizinine `compose.yaml` eklendi.

İki servis tanımlandı:

```text
postgres
bank-app
```

## PostgreSQL Servisi

```yaml
postgres:
  image: postgres:18
```

ile PostgreSQL containerı oluşturuldu.

Environment değerleri:

```yaml
POSTGRES_DB: bank_db
POSTGRES_USER: bank_user
POSTGRES_PASSWORD: ${BANK_DB_PASSWORD}
```

olarak tanımlandı.

## Docker Volume

Database verisinin container lifecycle’ından bağımsız kalması için:

```yaml
volumes:
  - bank_postgres_data:/var/lib/postgresql
```

kullanıldı.

Containerlar kaldırılıp yeniden oluşturulduktan sonra daha önce eklenen Customer kaydının hâlâ bulunduğu doğrulandı.

## Healthcheck ve Startup Order

PostgreSQL servisine:

```yaml
healthcheck:
  test: ["CMD-SHELL", "pg_isready -U bank_user -d bank_db"]
```

eklendi.

Bank uygulaması:

```yaml
depends_on:
  postgres:
    condition: service_healthy
```

ile PostgreSQL hazır olana kadar bekleyecek şekilde ayarlandı.

## Docker Network

Compose default network oluşturdu.

Spring Boot containerı PostgreSQL’e:

```text
jdbc:postgresql://postgres:5432/bank_db
```

ile bağlandı.

Buradaki `postgres`, Compose service adıdır.

## Port Mapping

```yaml
ports:
  - "8080:8080"
```

ile host `localhost:8080`, `bank-app` containerının 8080 portuna bağlandı.

Postman çağrıları aynı URL üzerinden devam etti.

## `.env` ve `.env.example`

Gerçek database password değeri Compose dosyasından çıkarıldı.

```yaml
${BANK_DB_PASSWORD}
```

kullanıldı.

Local `.env` dosyasında gerçek değer tutuldu ve Git tarafından ignore edildi.

Repository’ye güvenli örnek olarak:

```text
.env.example
```

eklendi.

## `.dockerignore`

Build context’i temizlemek için:

```text
target/
.git/
.idea/
*.iml
.DS_Store
.env
```

içeren `.dockerignore` oluşturuldu.

## Compose Kontrolü

```bash
docker compose config
```

ile Compose configuration doğrulandı.

## Containerları Çalıştırmak

```bash
docker compose up --build
```

ile iki servis birlikte başlatıldı.

Arka planda çalıştırmak için:

```bash
docker compose up -d
```

kullanıldı.

```bash
docker compose ps
```

ile `postgres` ve `bank-app` servislerinin çalıştığı görüldü.

## Docker İçindeki PostgreSQL

```bash
docker compose exec postgres psql -U bank_user -d bank_db
```

ile PostgreSQL containerına bağlanıldı.

Şu sorgularla kayıtlar kontrol edildi:

```sql
SELECT * FROM customers;
SELECT * FROM accounts;
SELECT * FROM transactions ORDER BY transaction_id;
```

## Uçtan Uca Test

Docker ortamında Postman üzerinden:

```text
Customer create
Deposit
Withdrawal
Transfer
Transaction history
```

test edildi ve sonuçlar PostgreSQL containerından doğrulandı.

## Volume Persistence Testi

```bash
docker compose down
docker compose up -d
```

sonrasında eski verilerin hâlâ database içinde olduğu görüldü.
